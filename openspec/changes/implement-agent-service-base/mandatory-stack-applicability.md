# Mandatory Stack Applicability Memo

- Change: `implement-agent-service-base`
- Scope: package baseline and stack applicability decisions only
- Status: Applied for dependency/config/OpenSpec baseline; source refactors remain in Agent/Client tasks.

## Decisions

| Stack item          | Applicability                               | Decision                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ------------------- | ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Next.js App Router  | Primary Client runtime                      | Keep `packages/client` on Next.js 16.2.9 and App Router. This remains the only Client routing/runtime model.                                                                                                                                                                                                                                                                                                                   |
| React / React DOM   | Primary UI runtime                          | Keep React and React DOM at 19.2.7 because `pnpm-workspace.yaml` overrides already pin both to 19.2.7 with Next 16.2.9. React 19.2.3 is not installed to avoid a silent override mismatch.                                                                                                                                                                                                                                     |
| React Compiler      | Applicable to Client build                  | Enable `reactCompiler: true` in `packages/client/next.config.ts` and add `babel-plugin-react-compiler` as a direct Client dev dependency.                                                                                                                                                                                                                                                                                      |
| TanStack Query      | Browser-safe Client state only              | Add `@tanstack/react-query` as a direct Client dependency, resolved at 5.101.0 to match the existing workspace override. It may be used in Client Components for browser-safe cache state only; Agent credentials and Agent RPC clients remain server-only.                                                                                                                                                                    |
| Drizzle ORM         | Mandatory for Agent DO SQLite and Client D1 | Add `drizzle-orm` to both `packages/agent` and `packages/client`. Agent persistence must use `drizzle-orm/durable-sqlite` or the current documented Drizzle Durable Object SQLite adapter while preserving `1 Agent ID = 1 AIAgent Durable Object instance = 1 aggregate root`. Client persistence must use `drizzle-orm/d1` for `client_managed_agents` and `client_agent_credential_refs` only. Prisma is not used anywhere. |
| shadcn/ui ecosystem | Applicable to Client UI                     | Add Radix Dialog/Slot, `class-variance-authority`, `clsx`, `tailwind-merge`, `lucide-react`, `react-hook-form`, `@hookform/resolvers`, `zod`, Tailwind, PostCSS, and shadcn-compatible `components.json`/utility baseline for Management Client UI.                                                                                                                                                                            |
| Vite                | Not a runtime stack for Client              | Do not introduce Vite as the Client runtime/build path. Next.js App Router remains primary; Vite may only appear as test/tool transitive infrastructure.                                                                                                                                                                                                                                                                       |
| React Router        | Not applicable                              | Do not introduce React Router. Next App Router owns Client routing.                                                                                                                                                                                                                                                                                                                                                            |
| KV                  | Not applicable without spec-backed use      | Do not add KV bindings or dependencies. No current `implement-agent-service-base` requirement makes KV authoritative.                                                                                                                                                                                                                                                                                                          |
| R2                  | Agent-owned blob/history storage            | Keep R2 use limited to Agent large payload, History, transcript, Tool result blob, artifact, archive, and export references.                                                                                                                                                                                                                                                                                                   |

## Supply-chain notes

- `minimumReleaseAge: 4320` remains unchanged.
- No `minimumReleaseAgeExclude` or `dangerouslyAllowAllBuilds` was added.
- Drizzle runtime dependency `drizzle-orm` does not require a new package-specific build-script approval. `drizzle-kit` is intentionally not added in this baseline because the repository still applies explicit SQL migrations through Wrangler; add it later only with a concrete migration-generation task and supply-chain review.
- Generated Agent outputs remain command-owned and were not hand-edited for this dependency/config pass.

## Follow-up constraints for implementers

1. TanStack Query cache data must be browser-safe and must not include Agent credential material, raw JWTs, private keys, Agent RPC clients, or direct Agent RPC invocation logic.
2. Prisma is not used anywhere. Agent and Client persistence implementation must use Drizzle ORM within their respective storage/repository layers.
3. Agent Drizzle usage is limited to the Agent storage persistence layer and must not leak into Agent domain/events/RPC layers.
4. Client Drizzle usage must only target Client-owned D1 tables (`client_managed_agents`, `client_agent_credential_refs`) and must not model Agent domain snapshots.
5. shadcn-style components must preserve the existing dark control-room visual direction documented in `client-management-ui-wireframe.md`.
6. Agent security/validation refactors may use `jose` and `zod`, but must preserve Connect binary Protobuf-only API boundaries.
